# 🧠 Brain Champ v2 — повний пакет

## Папка `github/` — гра (Mini App), 12 файлів. Усі завантажуються на GitHub в ОДНУ папку (корінь репозиторію)
index.html, style.css, config.js — сторінка, дизайн, налаштування
core.js, i18n.js, utils.js, sound.js, games.js, screens.js, engine.js — код гри
mascot.jpg, logo.jpg — картинки чоловічка-помічника

Оновлення старої версії: Add file → Upload files → вибери всі 12 файлів → Commit changes (однакові файли замінюються, нові додаються).
Через 1–2 хвилини GitHub Pages оновить гру. Якщо змін не видно — закрий і заново відкрий гру в Telegram.

## Що є в грі
- 📅 Щоденне тренування: 5 завдань на день (по одній грі з категорії), за них нараховуються бали. Максимум 1000 за день. Завдання однакові для всіх у цей день.
- 🎯 Звичайне тренування: будь-яка з 19 ігор, 5 рівнів складності, без балів.
- 19 ігор: математика (4), пам'ять (4), логіка (4), увага (4), реакція (3).
- Чоловічок-помічник вітає за часом доби і дає пораду.
- Звукові ефекти і тиха фонова музика (вмикаються і вимикаються в налаштуваннях).
- Профіль з аватаром Telegram, серія днів, мозковий рейтинг, топ гравців (натисни гравця, щоб відкрити його профіль у Telegram).
